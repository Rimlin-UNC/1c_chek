# Журнал изменений — Ямастер Чек

> Разработчик и владелец идеи: ООО «Ямастер» · [ymaster.ru](https://ymaster.ru) · info@ymaster.ru
> Формат: Semantic Versioning (MAJOR.MINOR.PATCH)

## [1.0.0] — 2026-09-22

Первый релиз системы по ТЗ.

### Добавлено
- **Backend (FastAPI + SQLAlchemy 2):**
  - приём сканов: строка QR / изображение (OpenCV) / ручной ввод / REST;
  - разбор QR 54-ФЗ с алиасами тегов, URL-вариантами и валидацией реквизитов;
  - дедупликация по ФН+ФД+ФП (уникальный констрейнт + приёмка);
  - асинхронная проверка чеков в ФНС: провайдеры `mock` и `fns`
    (openapi.nalog.ru: SOAP-получение временного токена, POST /check, автообновление токена);
  - кэш результатов проверки (30 дней) и журнал обращений к ФНС;
  - экспорт EnterpriseData (JSON/XML) + Push-API для 1С: ping/pull/ack;
  - настраиваемый маппинг «поле чека → реквизит 1С» с трансформациями;
  - JWT-аутентификация, PBKDF2-пароли, RBAC (админ/оператор), аудит всех действий;
  - WebSocket `/ws/status` — живые статусы обработки;
  - аналитика: сводные метрики, динамика по дням, источники;
  - демо-данные (python -m app.seed --demo).
- **Веб-клиент (SPA + PWA, без сборочных зависимостей):**
  - живое сканирование камерой (WebRTC + jsQR; BarcodeDetector при наличии);
  - загрузка фото drag-and-drop с клиентским предраспознаванием и серверным fallback;
  - обработка «несколько QR на фото» с выбором чеков;
  - офлайн-режим: локальная очередь сканов + автосинхронизация, Service Worker;
  - дашборд: KPI-анимации, SVG-графики (столбцы/кольца, тултипы), лента событий;
  - таблица чеков с фильтрами, массовыми операциями, карточкой чека (drawer);
  - конструктор маппинга, управление пользователями, журнал аудита, настройки ФНС/1С;
  - тёмная тема: glassmorphism, градиентная «аврора», микроанимации, адаптивность;
  - PWA: manifest, иконки, установка на телефон как приложение.
- **Интеграция 1С:** готовый общий модуль + регламентное задание (BSL),
  инструкция, схема дедупликации через регистр сведений.
- **Деплой:** install.sh (Ubuntu 24.04: venv, systemd, Nginx, certbot),
  Dockerfile, docker-compose.yml (PostgreSQL 17), .env.example.
- **Документация:** руководство пользователя, руководство по развёртыванию,
  интеграция с 1С, база знаний (ФНС, форматы QR), OpenAPI (Swagger/ReDoc).
- **Тесты:** pytest — разбор QR (стандарт/алиасы/URL/ошибки), экспорт, трансформации.

### Безопасность
- Секреты только через .env (в git не попадают); маскирование токенов в API;
- проверка прав на всех мутациях; логирование неудачных входов.
