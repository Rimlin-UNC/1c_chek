# Дизайн-система «Ямастер» (v1.19.0)

Разработчик и владелец идеи: ООО «Ямастер» · https://ymaster.ru · info@ymaster.ru

Стиль «Ямастер» — профессиональный инструмент, который уважает цифру и не
мешает работать. Позиционирование: бухгалтер — мастер своего дела, приложение
подчёркивает это: снижает когнитивную нагрузку, вызывает доверие, читаемость
данных важнее декора.

## 1. Палитра

| Роль | HEX | Применение |
|---|---|---|
| Корпоративный оранжевый | `#FF7A00` | CTA, активные элементы, брендинг. Не более 10–15% площади |
| Основной фон | `#FFFFFF` | Рабочие области, карточки, таблицы |
| Нейтральный фон | `#F5F5F5` | Подложка, разделители, второстепенные панели |
| Триада: индиго | `#4B0082` | Заголовки, акценты в отчётах, важные подписи |
| Триада: морская зелень | `#2E8B57` | Успех: «Проведено», «Оплачено», сверка сошлась |
| Триада: терракота | `#D9534F` | Ошибки, просрочки. Не «ядовитый» |
| Информационный | `#5BC0DE` | Ссылки, подсказки, уведомления |
| Текст | `#333333` | Основной текст |

Тёмная тема (опционально, мягкие тона): фон `#1E1E1E`, оранжевый `#E06D00`,
текст `#E0E0E0`, зелень `#3CB371`, красный `#C94C4C`.

Смысловые якоря: зелёный — «порядок и правила», синий — «ориентир», красный —
сигнал к действию. Оранжевый добавляет энергии, но не заменяет якоря.

## 2. Шрифты и типографика

| Роль | Шрифт | Применение |
|---|---|---|
| Интерфейс | **Inter** (fallback: Segoe UI, system-ui) | Меню, кнопки, подписи, таблицы, отчёты |
| Цифры и таблицы | Inter с `font-variant-numeric: tabular-nums` | Числовые колонки, суммы, даты, номера |
| Коды | **JetBrains Mono** | Коды счетов, ИНН, КПП, ФД, тех. идентификаторы |
| Акцент | **Caveat** (рукописный) | Только заголовки разделов и акцентные надписи |

Опора на форумы бухгалтеров (buh.ru, buhonline.ru, buhsoft.ru, klerk.ru):
крупный читаемый шрифт; табличные цифры; чёткое различие 0/O, 1/l, 5/S;
цифры не выходят за высоту строки; ГОСТ Р 7.0.97-2016 (12–14 pt) соблюдён
по духу: базовый размер интерфейса — 15 px, минимум 14 px.

| Элемент | Размер | Примечание |
|---|---|---|
| Основной текст | 15 px (мин. 14) | line-height 1.5 |
| Таблицы | 13–14 px | tnum, межстрочный 1.35 |
| Заголовки разделов | 18–26 px | Caveat — рукописный акцент |
| Подписи, метки | 12–13 px | letter-spacing +0.015em |
| Итоговые суммы | тот же размер | `font-weight: 600` |

Критическое требование: никакой фиксированной геометрии под конкретный DPI —
относительные единицы, масштабирование 120 dpi не ломает вёрстку («строки
лезут друг на друга» — прямая жалоба с buhsoft.ru).

## 3. Кнопки

- **Primary — тёмная** (`#333333`): основное действие экрана.
- **Accent — оранжевая**: второстепенные, но важные действия.
- **Ghost — серая**: все остальные.

## 4. Текст в интерфейсе

- Ясность и однозначность; краткость; нейтральный деловой тон.
- Стандартизация: одинаковые действия — одинаковыми словами.
- Запрещено: восклицательные знаки в уведомлениях, юмор/сленг в системных
  сообщениях, абзацы длиннее 2–3 строк в подсказках, КАПС целыми фразами,
  мелкий шрифт для важной информации.

## 5. Журнал действий (v1.19.0)

- Событие = фраза «кто + что сделал», детали — в кавычках «…»
  (вложенные кавычки — „…“).
- Группировка по дням: Сегодня / Вчера / «12 октября».
- Цветовой смысл строк: зелёный — успех, красный — ошибка, оранжевый —
  внимание, синий — информация.
- Источник формулировок — `app/services/audit_human.py` (единый для ленты
  и журнала); неизвестные действия показываются как есть, без потери данных.

## 6. UX-принципы (адаптация «Точки»)

- Слоистость и мягкие тени панелей; предсказуемая навигация:
  слева — навигация, сверху — контекст, центр — рабочая область.
- Экспрессивность снижена против «Точки»: меньше цветовых пятен,
  сдержанные микроанимации (уважается `prefers-reduced-motion`).
- Иерархия данных: таблицы и отчёты — главный контент.

## 7. Токены для разработки

CSS-переменные (см. `app/static/css/app.css`, блок v1.19.0):
`--accent`, `--ok`, `--bad`, `--info`, `--warn`, `--indigo`,
`--font-main`, `--font-num`, `--font-mono`, `--font-accent`.
Служебный класс `.tnum` — включает табличные цифры;
`.font-accent` — рукописный заголовок раздела.
