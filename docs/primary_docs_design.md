## Решения, принятые агентом

- Документы сдают и сотрудники компании-клиента (программа, Telegram, MAX), и бухгалтер.
- Срок сдачи по умолчанию — 5-е число следующего месяца, «час икс» — настройка компании.
- Напоминания — по уже подключённым каналам (Telegram, MAX, почта), без новых сервисов.
- Запрос документа и каждое напоминание записываются в журнал — это и есть письменный след.

## Решения по УПД (1.70.94)

- Исходный XML не хранится: только реквизиты, строки, итог проверки и отпечаток файла (SHA-256) — для поиска дублей.
- Документ с ошибками сохраняется со статусом «Ошибки»: его видно в реестре и можно разобрать с поставщиком. Не принимаются только титул покупателя, корректировочные документы (УКД) и файлы с неизвестной функцией.
- УПД, загруженный бухгалтером, попадает в его компанию, даже если покупатель в документе другой, — с замечанием. Администратор без выбранной компании получает компанию по ИНН покупателя, если она одна.
- Дубль — тот же файл или тот же документ: ИНН продавца, номер, дата и номер исправления; исправление — новый документ.
- Коды маркировки не сохраняются; подписи и печатные формы из архива пропускаются.
- Разбор XML — defusedxml без DTD; лимиты: файл 5 МБ, архив 20 МБ, распакованное 50 МБ, 50 документов за раз.
- Код: `app/primary/` (разбор и проверка — `upd.py`), экран — `app/static/js/primary.js`, тесты — `tests/test_primary_upd.py` и `tests/js/primary.test.js`.
