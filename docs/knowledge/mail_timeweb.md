# Почта «Ямастер Чек» на Timeweb

**С версии 1.45.0** почта системы (письма кабинета и бот рассылок Чек-Пула)
уходит через почту Timeweb. Самохостингованный постфикс больше не нужен —
его снимает `remove-mail.sh` (см. ниже).

## Реквизиты ящика

| Что | Значение |
|---|---|
| Ящик | `chek@ymaster.ru` |
| Панель управления ящиком | <https://mail.timeweb.com> |
| SMTP (отправка) | `smtp.timeweb.ru`, порт **465**, SSL |
| POP3 | `pop3.timeweb.ru:995` (SSL) |
| IMAP | `imap.timeweb.ru:993` (SSL) |
| Пароль | знает админ; меняется в панели Timeweb |

Порт 465 — защищённое соединение **с первого байта** (SMTP_SSL):
приложение понимает это автоматически — `app/pool/mailer.py`
(`port == 465 → smtplib.SMTP_SSL`, иначе `STARTTLS`).

## Настройка в приложении (1 минута)

1. Админ → **Почтовый центр** (`#/mail`).
2. Нажать **«Заполнить для Timeweb»** — поля примут вид:
   - сервер: `smtp.timeweb.ru`, порт: `465`
   - пользователь и адрес отправителя: `chek@ymaster.ru`
   - STARTTLS: выключен (465 уже SSL)
3. Ввести **пароль ящика** → «Сохранить».
4. В поле теста — свой e-mail → **«✉ Тестовое письмо»**.
   Письмо пришло — готово: бот рассылок и письма кабинета шлются через
   этот ящик автоматически (единый mailer).

## Смена пароля ящика

1. В панели <https://mail.timeweb.com> сменить пароль ящика.
2. В Почтовом центре нажать **«Сбросить пароль ящика»**
   (`DELETE /api/v1/mail-admin/config/password`) — сохранённый пароль
   стирается (фиксируется в аудите).
3. Ввести новый пароль → «Сохранить» → тестовое письмо.

## Удаление самохостингованной почты (однократно)

```bash
sudo bash /opt/ymaster-check/deploy.sh --remove-mail
```

- сначала архивирует всё в `/root/mail-legacy-backup-<дата>.tar.gz`
  (ключи DKIM, конфиги postfix/opendkim, DNS-подсказку, почту `chek`);
- снимает пакеты `postfix`, `opendkim`, `opendkim-tools`, `mailutils`
  и их конфиги, удаляет `/etc/dkimkeys`, `/root/mail-dns-records.txt`;
- системного пользователя `chek` удаляет только если он служебный
  (shell `nologin`), иначе просит решить вручную;
- **не трогает:** приложение `/opt/ymaster-check`, базу, Nginx, UFW,
  fail2ban, certbot.

После этого порты 25/8891 свободны, исходящая почта — только через
Timeweb (это снижает риск попадания сервера в чёрные списки).

## Если письмо не ушло

- «Authentication failed» — пароль ящика неверный/устарел → смена через
  панель Timeweb + «Сбросить пароль ящика» (см. выше).
- Таймаут — провайдер блокирует исходящий 465: проверить у хостера.
- Письма в «Спаме» — добавить `chek@ymaster.ru` в контакты; для домена
  ymaster.ru у Timeweb прописаны SPF/DKIM — проверять их в панели,
  на своём сервере DKIM больше не настраивается.
