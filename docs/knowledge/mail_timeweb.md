# Почта «Ямастер Чек» на Timeweb (v1.44.2)

**С версии 1.44.2** отправка через порт **465** работает как SMTP_SSL
(защищённое соединение с первого байта) — почта Timeweb поддерживается.
Самохостингованный постфикс не используется.

## Реквизиты ящика

| Что | Значение |
|---|---|
| Ящик | `chek@ymaster.ru` |
| Панель управления ящиком | <https://mail.timeweb.com> |
| SMTP (отправка) | `smtp.timeweb.ru`, порт **465**, SSL |
| POP3 | `pop3.timeweb.ru:995` (SSL) |
| IMAP | `imap.timeweb.ru:993` (SSL) |
| Пароль | знает админ; меняется в панели Timeweb |

Порт 465 приложение распознаёт автоматически: `app/pool/mailer.py`
(`port == 465 → smtplib.SMTP_SSL`, остальные порты — STARTTLS по флагу).

## Настройка в приложении (Почтовый центр, админ)

1. Админ → **Чек-Пул → Почтовый центр** — поля SMTP-сервера:
   - сервер: `smtp.timeweb.ru`
   - порт: `465`
   - пользователь: `chek@ymaster.ru`
   - пароль: пароль ящика
   - адрес отправителя (From): `chek@ymaster.ru`
   - флаг STARTTLS не важен для 465 (соединение уже защищённое)
2. **Сохранить** → тестовое письмо на свой e-mail.
3. Письмо пришло — готово: бот рассылок и письма кабинета шлются через
   этот ящик автоматически (единый mailer).

## Смена пароля ящика

1. Сменить пароль в панели <https://mail.timeweb.com>.
2. В Почтовом центре ввести новый пароль → «Сохранить» → тестовое письмо.

## Если письмо не ушло

- «Authentication failed» — пароль ящика неверный/устарел → сменить в
  панели Timeweb и сохранить новый в Почтовом центре.
- Таймаут — провайдер блокирует исходящий 465: проверить у хостера.
- Письма в «Спаме» — попросить получателей добавить `chek@ymaster.ru`
  в контакты; SPF/DKIM домена настраиваются в панели Timeweb.
