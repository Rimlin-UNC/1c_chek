# База знаний: API ФНС «Проверка чека ККТ»

> Ямастер Чек · ООО «Ямастер» · ymaster.ru · info@ymaster.ru

## Как получить доступ (Мастер-токен)

1. Направьте заявку в ФНС на подключение к «Открытому API проверки чека ККТ»
   (официальный сервис ФНС России, адрес сервиса — `openapi.nalog.ru`).
2. В заявке укажите назначение (проверка чеков сотрудниками для авансовых отчётов),
   ИНН организации и контактные данные.
3. В ответном письме технической службы ФНС вы получите:
   - **Мастер-токен** (строка вида `30xxxx.xxxxxxxx...`);
   - лимиты: количество запросов в сутки;
   - руководство пользователя и схемы сервиса.

## Как устроена аутентификация

Двухступенчатая:

1. **Мастер-токен → временный токен.** SOAP-запрос `GetMessage` к
   `https://openapi.nalog.ru:8090/open-api/AuthService/0.1` с телом
   `AuthRequest → AuthAppInfo → MasterToken`. В ответе — элемент `<Token>`.
   Временный токен живёт ограниченное время (рекомендуем кэшировать на несколько часов).
2. **Временный токен → проверка чека.** POST-запрос
   `https://openapi.nalog.ru:8090/open-api/api/2/check` с заголовком `token: <временный>`
   и `ClientAppId: <идентификатор приложения>`.

Тело запроса проверки (массив, до 100 чеков за раз):

```json
[{
  "date": "2025-09-01T14:30:00",
  "sum": 152050,
  "fn": "9999078902001234",
  "fd": "54321",
  "fp": "812345678",
  "type": "income"
}]
```

`sum` — в копейках; `type`: `income` (приход), `incomeRefund` (возврат прихода),
`expense`, `expenseRefund`.

Ответ: `{"Code": 0}` — чек найден и корректен; иные коды — ошибки/не найден
(расшифровка в руководстве ФНС). HTTP 401/403 — временный токен истёк:
получите новый и повторите (в «Ямастер Чек» это делается автоматически).

## Включение в «Ямастер Чек»

Вариант 1 (интерфейс): **Настройки → Проверка чеков (ФНС)** → «Реальное API ФНС» →
вставьте Мастер-токен → сохранить.

Вариант 2 (.env, до старта):

```
FNS_PROVIDER=fns
FNS_MASTER_TOKEN=30xxxx.xxxxxxxx...
FNS_CLIENT_APP_ID=YOUR-APP-ID
```

## Лимиты и экономия

- Кэш результатов включён по умолчанию: **30 дней** (`FNS_CACHE_TTL_DAYS`) —
  повторная проверка того же чека не расходует лимит.
- Проверяйте пачками (кнопка «Проверить все новые»), а не по одному.
- Не удаляйте записи журнала `fns_log` — это доказательная база по спорным чекам.

## Известные особенности

- Данные чека от ОФД поступают в ФНС с задержкой (обычно до 3 суток) — статус
  «не найден» для свежего чека не означает фальшивку; повторите проверку.
- QR-код некоторых касс содержит тег `fpd` вместо `fp` и разделитель `;` —
  парсер системы обрабатывает эти случаи автоматически.
- Временный токен нельзя кэшировать «навсегда» — при 401 код обновляет его сам
  (`app/services/fns.py`).

## Конфиденциальность

Мастер-токен — секрет: храните в `.env` с правами 600, не публикуйте в репозитории,
не вставляйте в задачи/багтрекеры. В веб-интерфейсе токен отображается маскированным.
