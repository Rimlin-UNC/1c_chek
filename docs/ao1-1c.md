# Интеграция авансового отчёта (АО-1) с 1С

Разработчик и владелец идеи: ООО «Ямастер» · https://ymaster.ru · info@ymaster.ru

## Источники по официальной форме

- Постановление Госкомстата РФ от 01.08.2001 № 55 — унифицированная форма
  № АО-1 «Авансовый отчёт», ОКУД 0302001 (kontur.ru/normativ, documentId 9851).
- Порядок заполнения: лицевая сторона (реквизиты, подотчётник, расчёт сумм
  с бухгалтерской записью, утверждение, расписка) + оборотная сторона
  (таблица подтверждающих документов). С 30.11.2020 организация вправе
  применять собственную форму (закрепив в учётной политике), АО-1 —
  классика и полностью поддержана в Ямастер Чек.

## Где данные в Ямастер Чек

- `POST /api/v1/receipts/advance-report` — сбор отчёта за период; в ответе:
  - `requisites.Организация` — реквизиты из **карточки предприятия**
    (card_json из ЕГРЮЛ/ЕГРИП): НаименованиеПолное, НаименованиеСокращенное,
    ИНН, КПП, ОГРН, ОКПО, Адрес, Телефон, Руководитель;
  - `person` — ПодотчетноеЛицо: ФИО, Должность, ТабельныйНомер;
  - `rows[]` — документы (чеки): даты, ФД/ФН/ФП, продавец, ИНН, сумма,
    статья расходов.
- Печать: `ao1Print` (app/static/js/printpack в app.js) — официальная форма
  на двух страницах (лицевая + оборотная), «Сохранить как PDF» в браузере.

## Кнопка «⬇ JSON для 1С»

Формат выгрузки (файл `avansovy-otchet-1c-<с>_<по>.json`):

```json
{ "АвансовыйОтчет": {
    "НомерДокумента": "АО-2026-10-42", "ДатаДокумента": "2026-10-04",
    "ОтчетныйПериод": "2026-10",
    "Организация": { "НаименованиеПолное": "…", "ИНН": "…", "КПП": "…",
                     "ОГРН": "…", "ОКПО": "…", "Адрес": "…",
                     "Руководитель": "…" },
    "СтруктурноеПодразделение": "…",
    "ПодотчетноеЛицо": { "ФИО": "…", "Должность": "…", "ТабельныйНомер": "…" },
    "НазначениеАванса": "На хозяйственные расходы",
    "Суммы": { "ПолученоИзКассы": "0.00", "ПолученоНаКарту": "0.00",
               "ИтогоПолучено": "0.00", "Израсходовано": "0.00",
               "Остаток": "0.00", "Перерасход": "0.00",
               "СчетДт": "71.01", "СчетКт": "50.01",
               "РКО": "№ 12 от 05.10.2026", "ПлатёжноеПоручение": "№ 45 от 05.10.2026" },
    "Документы": [ { "НомерСтроки": 1, "ДатаДокумента": "…",
                     "НомерДокумента": "ФД №…", "НаименованиеДокумента": "Кассовый чек",
                     "НаименованиеРасхода": "…", "Продавец": "…", "ИННПродавца": "…",
                     "ФН": "…", "ФД": "…", "ФП": "…", "Сумма": "…",
                     "СтатьяРасходов": "…", "СчетУчета": "44.01" } ],
    "Итого": { "Сумма": "…", "КоличествоДокументов": 0, "Листов": 1 },
    "ГлавныйБухгалтер": "…", "Руководитель": "…"

```

Ключи повторяют реквизиты документа «Авансовый отчёт» 1С:Бухгалтерии 8.3
(ред. 3.0), что позволяет загрузить файл обработкой импорта JSON/HTTP-сервиса
без ручного маппинга (см. helpme1s.ru — примеры загрузки авансовых отчётов,
habr.com/ru/articles/657991 — обмен по API).

## Дополнительно

- Проводки по умолчанию: выдача Дт 71.01 Кт 50.01 (из кассы) / 51 (карта),
  принятие расходов Дт 44.01 (настраивается в форме перед сбором отчёта).
- Статьи расходов переносятся в `СтатьяРасходов` каждой строки.
