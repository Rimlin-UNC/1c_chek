# План уникальности: что сделает «Ямастер Чек» №1 у бухгалтеров и коммерческих организаций

*Версия продукта на момент плана: 1.15.0 · Дата: октябрь 2026 · ООО «Ямастер», ymaster.ru*

Принцип: **не копировать 1С:Сканер чеков, а закрывать то, за что он не берётся** —
работу бухгалтера-аутсорсера с десятками компаний, дисциплину подотчётников и
доверие (безопасность, аудит, независимость от экосистем).

## Блок А. Доверие и безопасность (уже начато в v1.15.0)

| Фича | Суть | Почему это уникальность | Приоритет |
|---|---|---|---|
| ✅ Сейф секретов | API-ключи зашифрованы в БД (Fernet), показ по паролю с аудитом | ни один «сканер чеков» не даёт такой прозрачности | сделано 1.15.0 |
| ✅ Самовосстановление апдейтера | обновление из приложения работает даже без .git (init+fetch) | обновления «в один клик» без админа | сделано 1.16.0 |
| Журнал аудита с экспортом | кто сохранил/показал ключ, кто удалил чек — выгрузка для проверок | аргумент на переговорах с бухгалтером: «всё фиксируется» | ★★☆ |
| 2FA (TOTP) для админа | Google Authenticator и совместимые | требование банков/франчайзи при внедрении | ★★☆ |
| Белые ярлыки | аутсорсер загружает свой логотип/домен — продукт как его собственный сервис | виральность: каждый аутсорсер приводит своих клиентов | ★★★ |

## Блок Б. Контрагенты глубже всех (строим на Checko)

| Фича | Суть | Почему это уникальность | Приоритет |
|---|---|---|---|
| Светофор контрагента | в карточке компании: возраст, капитал, статус, массовый адрес, ОКВЭД vs фактические чеки → зелёный/жёлтый/красный риск-индикатор | данные уже приходят из Checko — нужна только интерпретация; у 1С:Сканера этого нет вообще | ★★★ |
| Автопроверка при добавлении | при создании компании — предпросмотр ЕГРЮЛ уже есть; добавить предупреждение «контрагент ликвидируется/массовый адрес» | бухгалтер избегает вычетов по проблемному контрагенту | ★★☆ |
| Мониторинг изменений | при обновлении карточки — diff: «сменился директор, статус → ликвидация» + уведомление админу | никто в нише не следит за контрагентом после добавления | ★★☆ |
| Суды/ФССП (Checko API) | исполнительные производства и арбитражи компании в карточке | Checko отдаёт готовые методы — дешёвая реализация, высокая ценность | ★☆☆ |

## Блок В. Дисциплина подотчётников (закрываем главный источник боли)

| Фича | Суть | Почему это уникальность | Приоритет |
|---|---|---|---|
| Telegram-бот напоминаний | «Иван, чек за обед?» в 18:00; отчёт собран — «спасибо, бухгалтер получил» | собираемость чеков 60% → 90%+, эффект ощущает бухгалтер | ★★★ |
| Персональная страница сотрудника | QR-код в столовой/на стенде: навёл камеру — открылся сканер без входа (сессия в cookie) | снихает порог «лень открывать приложение» до нуля | ★★☆ |
| Лимиты и аналитика по сотруднику | «Петров в месяц ~15 тыс. ₽, 40% — обеды»; аномалии (чек на 50 тыс. ночью) | бухгалтер видит не кучу чеков, а поведение | ★★☆ |
| Геймификация сдачи | бейджи «сдал за день», «месяц без просрочек» | культура сдачи чеков — немодная, но дефицитная | ★☆☆ |

## Блок Г. Аутсорсер как главный промоутер

| Фича | Суть | Почему это уникальность | Приоритет |
|---|---|---|---|
| Партнёрский кабинет | все компании в одном окне: сводные АО, массовые операции, отчёт по всем клиентам за месяц | 1 аккаунт = 10–50 платящих компаний; у 1С:Сканера «одна база = одна компания» | ★★★ |
| Массовый сбор АО | «собрать авансовые отчёты по всем компаниям за сентябрь» → zip с PDF+CSV | месяц-закрытие за минуты вместо дня | ★★★ |
| Биллинг на аутсорсере | тарификация по числу клиентских компаний, счёт/акт автогенерацией | снимает барьер «мне это не нужно, я сервис веду для клиентов» | ★☆☆ |

## Блок Д. Интеграции и «наши» каналы

| Фича | Суть | Почему это уникальность | Приоритет |
|---|---|---|---|
| HTTP-сервис 1С (OData/HTTP) | 1С сама забирает чеки по расписанию — уже есть выгрузка 1С, оформить как «подключение за 15 минут» с инструкцией | совместимость вместо войны с 1С | ★★☆ |
| Экспорт в Сбербизнес/банки | выгрузка подтверждённых расходов для кредитных заявок | уникальный сценарий «приложил к кредиту» | ★☆☆ |
| ЭДО-выгрузка (Диадок/СБИС) | формализованный документ авансового отчёта в ЭДО | горизонт 2+ лет, когда ЭДО дойдёт до подотчётов | ★☆☆ |

## Очередность внедрения (по эффекту/затратам)

1. ✅ **сделано в 1.16.0** — Светофор контрагента, Telegram-бот, массовое обновление ЕГРЮЛ, самовосстановление апдейтера.
2. **v1.17.0 — Партнёрский кабинет v2**: zip со сводными АО всех компаний, массовые операции над чеками, биллинг по числу компаний.
3. **v1.18.0 — Белые ярлыки** (логотип/название в шапке и PDF для каждого аутсорсера).
5. Далее по таблицам выше — мониторинг контрагентов, 2FA, аналитика сотрудников.

Метрика успеха: «время закрытия месяца с подотчётами» — целевой показатель < 1 часа
на компанию; и «собираемость чеков» ≥ 90% (Telegram-напоминания).
