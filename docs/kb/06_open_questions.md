## Вопросы к владельцу

- **Q-25.** Фаза 4, часть 2 — реестр и Чек-Пул как копии единой записи: подход «вариант В
  по шагам» (4а сверка и готовность → 4б единая точка записи → 4в чтение из единой записи
  → 4г сжатие отдельным решением). Первый выпуск 1.70.88 — 4а, для пользователей ничего не
  меняется. → **Ответ владельца (03.11.2026): да** — T-37 в работе; T-37…T-40, [проект, раздел 12](../single_base_design.md#12-фаза-4-часть-2-реестр-и-чек-пул--копии-единой-записи-проект-03112026).
- **Q-26.** Мягкая регистрация архива: в единую запись попадают только чеки без
  расхождений, реестр и пул не меняются, спорные остаются как сейчас. Запуск: (а) фоном
  после обновления; (б) только командой владельца после `--dry-run`; (в) пока нет.
  → **Ответ владельца (03.11.2026): (б)** — только командой владельца после `--dry-run`;
  фоновый запуск не делается → T-37, T-39, T-07.
- **Q-27.** Сжатие (4г) закрывает откат ниже 4г и заменяет ADR-03 для фискальных колонок.
  → **Ответ владельца (03.11.2026): отложить** до отдельного решения → T-40.
- **Q-28.** Шаг 4в: копия реестра бывает беднее единой записи — компания
  отсканировала QR, а продавца, кассира и позиции единая запись знает из Чек-Пула.
  Показывать ли компании эти данные в карточке и выгрузке в 1С: (а) данные единой записи;
  (б) только своей копии, как сейчас; (в) с пометкой «из единой записи», в 1С — только своё?
  → **Ответ владельца (03.11.2026): (в)** — в карточке чека данные единой записи с пометкой,
  в выгрузку в 1С — только данные копии компании; T-39, [проект, раздел 12.7](../single_base_design.md#127-вопросы-владельцу).
  Там же: разбор расхождений данных между копиями (T-30, [#22](https://github.com/Rimlin-UNC/1c_chek/issues/22))
  отложен до переноса архива (#10).

- **Q-29.** Нововведения из [исследования](10_research.md): какие брать после шага 4в?
  Без решения агент берёт только то, что не меняет поведения для компаний: T-41
  (контрактные тесты), T-42 (офлайн-очередь в MAX), T-44 (подсказка статьи), T-49
  (зависимости). Решение нужно для T-43 (флаги позиций), T-45 (банковская выписка),
  T-46 (согласование отчётов), T-47 (чеки из почты), T-48 (MCP для ИИ-ассистентов).
  Рекомендация — T-46 и T-45: они закрывают подотчёт целиком.
  → **Ответ владельца (03.11.2026, issues #28, #30–#33):** T-43 — да (запрет: алкоголь и подобное,
  продукты питания; профиль — стройка), T-45 — да, T-46 — да (72 часа — согласовано),
  T-47 — да, T-48 — позже или платно → [стратегия](11_strategy.md).
