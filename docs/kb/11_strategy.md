# 11. Стратегия: приложение № 1 для крупных компаний и аутсорсинговых бухгалтерий

Принято владельцем 03.11.2026 (ответы в сессии и в issues

## Видение

Всё, что сотрудник потратил и что пришло от поставщика, — проверено, согласовано и
попадает в 1С без ручного ввода. Один бухгалтер ведёт в разы больше подотчётников и
клиентов, чем сегодня.

**Кому:** крупным компаниям с подотчётом — в первую очередь стройка и стройматериалы;
аутсорсинговым бухгалтериям — десятки клиентов на одного бухгалтера; малому бизнесу —
через облако.

## Почему мы станем № 1

| Сила | У нас | Ближайший конкурент |
|---|---|---|
| Чек проверен ФНС и не дублируется между компаниями | есть: единая база ([ADR-20](../ARCHITECTURE.md#adr-20)) | 1С:Сканер чеков проверяет, но не видит дубли между компаниями |
| Политика на уровне позиций: алкоголь и подобное, продукты питания — сразу видно | T-43 | Expensify (за рубежом) |
| Согласование с подписью и автосогласованием через 72 часа | T-46, [ADR-24](../ARCHITECTURE.md#adr-24) | Saby, Expensify |
| Сверка с банковской выпиской: корпоративная карта или личные деньги к возмещению | T-45 | Expensify; в России — вручную в 1С |
| 1С без ручного ввода: EnterpriseData, затем расширение с подтверждением | T-51, T-52, [ADR-22](../ARCHITECTURE.md#adr-22) | 1С:Сканер чеков — только внутри 1С |
| Рабочее место аутсорсера: все клиенты в одном окне, очередь, напоминания | T-50 | Saby Buhta, 1C-WiseAdvice |
| Мессенджеры (Telegram, MAX) и обновление из программы с откатом | есть | редко у конкурентов |

## Горизонты

**Горизонт 1 — ближайшие выпуски** (без новых решений владельца):

1. T-39 — шаг 4в: в карточке чека данные единой записи с пометкой, кнопка «Подставить».
2. T-43 — запрещённые позиции: алкоголь и подобные товары (табак, никотин), продукты
   питания; профиль компаний — строительство и стройматериалы.
3. T-46 — согласование авансового отчёта: сотрудник → руководитель → бухгалтер,
   простая электронная подпись, 72 часа без ответа — согласовано.
4. T-45 — банковская выписка (формат обмена 1С): операции корпоративной карты без чека,
   чеки, оплаченные лично, — к возмещению сотруднику.
5. T-41 — контрактные тесты «интерфейс ↔ API» — защита от ошибок вроде 1.70.89.

**Горизонт 2:** T-51 — выгрузка EnterpriseData; T-50 — рабочее место аутсорсера;
T-53 — электронные УПД из ЭДО; T-47 — чеки из почты; T-44 — подсказка статьи;
T-42 — офлайн-очередь в MAX.

**Горизонт 3:** T-52 — расширение 1С с HTTP-сервисом; T-54 — сервис распознавания
первички; T-55 — облачная поставка; T-56 — «коробка» для крупной компании (установщик,
единый вход SSO); T-48 — MCP для ИИ-ассистентов — позже или платно; T-49.

## Риски — критический взгляд

| Риск | Чем грозит | Что делаем |
|---|---|---|
| Проверка ФНС идёт неофициальным каналом с паузами | облаку на тысячи чеков в день не хватит лимитов | до запуска облака понадобится решение владельца об официальном API ФНС «Проверка чека» (заявление с ЭП); блок ФНС не трогаем без «да» (ADR-05) |
| SQLite — один писатель | предел для крупных клиентов | новые установки — PostgreSQL ([ADR-21](../ARCHITECTURE.md#adr-21)); каждый тест — на обеих базах |
| Разные конфигурации 1С и версии EnterpriseData | выгрузка не встанет у части клиентов | начинаем с БП 3.0; проверка по схеме формата; для расширения — тестовая база 1С (требует уточнения) |
| Банковские и персональные данные | 152-ФЗ, утечки | хранить минимум, срок хранения — настройкой, доступ — по ролям, журнал |
| Автосогласование через 72 часа | спор «я не согласовывал» | событие в журнале, уведомления до срока, положение об ЭП в компании |
| Ширина вместо глубины | много начатого, мало готового | горизонт 1 — по одному выпуску на задачу, со стандартом выпуска |

## Метрики

- Доля чеков, дошедших до 1С без ручного ввода.
- Время от скана до проводки в 1С.
- Число подотчётников и клиентов на одного бухгалтера.
- Доля нарушений политики, пойманных до согласования.
