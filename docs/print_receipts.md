# Печать чеков и приложения к авансовому отчёту

Выберите чеки в реестре и нажмите «Напечатать чек». В диалоге браузера
выберите принтер или «Сохранить как PDF», бумагу A4, масштаб **100%**,
поля **нет**, колонтитулы отключите. Проверьте предварительный просмотр:
некоторые принтеры имеют непечатаемые поля или самостоятельно уменьшают
страницу. Для контроля можно измерить ширину чека линейкой: она должна
быть 72 мм. В настройках PDF не используйте «вписать в страницу».

На портретном A4 расположены две колонки 72 мм: три без уменьшения на
листе шириной 210 мм не помещаются. Части чеков укладываются в свободные
места колонок; длинный чек разбивается между блоками с пометками
продолжения. Если отдельный блок слишком высок для листа, печать
останавливается с ошибкой вместо обрезания. Если карточка одного из
выбранных чеков не загрузилась, весь набор не печатается молча частично.

Печатается **восстановленная копия** по данным карточки, а не изображение
бумажного оригинала магазина. Доступные позиции, реквизиты и способы
оплаты выводятся из сохранённых данных; отсутствующие данные восстановить
нельзя. Если нет позиций или не удалось получить QR, это отмечается.
Для авансового отчёта используйте существующие форму АО-1 и CSV-выгрузку;
перед сдачей проверьте суммы, комплект документов и требования бухгалтерии.

## Отчёт с чеками одним PDF

В «Собрать авансовый отчёт» после предпросмотра выберите «Только АО-1»
или «АО-1 + чеки одним PDF». Сначала идёт форма, затем приложения с
номерами строк отчёта; листы с чеками раскраиваются по 72 мм. В форме с
чеками число листов приложений считается по раскрою; в варианте без чеков
его следует вписать вручную. Для нескольких подотчётных лиц формируется
**сводная ведомость**, а не отдельные индивидуальные АО-1.

Печать комплекта рассчитана на актуальный Chromium/Chrome/Edge с поддержкой
именованных страниц CSS: у формы поля 20/15/10/10 мм, у листов с чеками —
нулевые. В диалоге выберите A4, масштаб 100%, поля по умолчанию (не задавайте свои), отключите колонтитулы и
проверьте все страницы в предпросмотре. Чеки представляют собой копии по
данным системы, а не оригиналы. Сохранение PDF само по себе не подтверждает
пригодность документов для налогового учёта: бухгалтер проверяет форму,
реквизиты, суммы, первичные документы, подписи и требования организации.
При возвратах, личных расходах или неизвестном типе операции печать отчёта
заблокирована до ручного оформления в бухгалтерской системе. Чеки разных
организаций необходимо оформлять раздельно.
